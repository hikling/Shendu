# 每日复盘信息层级与视觉方向

## 产品判断

慎独是每日独处时使用的个人复盘工具。首屏只回答三件事：今天是哪一天、复盘处于什么状态、现在可以做什么。日期是这页的视觉锚点，不以统计数字或装饰插画开场。四区是自由跳转的目录，顺序只用于阅读，不设置门槛。

## 灰阶线框

桌面（约 1440px）：

```text
┌──────────────┬──────────────────────────────────────────────────┐
│ 慎独         │ 每日复盘                            [辅助信息]   │
│              ├──────────────────────────────────────────────────┤
│ 复盘         │  今日 · 日期                                      │
│  每日 ← 当前  │  今天的复盘状态                                   │
│  每周        │  一句简短引导                   [开始/继续复盘]    │
│  每月        ├──────────────────────────────────────────────────┤
│  90 天/年度   │  复盘目录  [证据 已填写] [反思 待填写] ...         │
│  重大决策     ├──────────────────────────────────────────────────┤
│ 记录与验证   │  当前书写区标题 · 简短说明                         │
│  历史/行动   │  ┌────────────────────────────────────────────┐  │
│ 数据与设置   │  │ 当前区表单，稳定不透底的书写表面              │  │
│  备份/设置   │  └────────────────────────────────────────────┘  │
│  账户        │  [保存草稿]  未保存状态         [完成并锁定]       │
└──────────────┴──────────────────────────────────────────────────┘
                                        [辅助面板按需覆盖主区域]
```

手机（约 390px）：

```text
┌──────────────────────────────┐
│ [菜单] 每日复盘       [辅助] │
├──────────────────────────────┤
│ 今日 · 日期                   │
│ 复盘状态                     │

├──────────────────────────────┤
│ 复盘目录（两列或可换行）     │

│ [行动 待填写][日记 待填写]   │

└──────────────────────────────┘
```

## 状态与交互

- 新草稿：首屏主动作“开始今日复盘”，进入证据区；可直接点击任一区。
- 草稿：主动作“继续今日复盘”，返回本次会话当前区；重新加载后默认从证据区进入，四区内容从记录恢复。
- 四区总览：待填写/已填写从 DOM 当前输入派生；“已填写”只表示有内容，完成仍按原校验。
- 已锁定或历史周期：主动作改为“查看复盘”，四区可读不可编辑；不显示误导性的保存动作。
- 切区：只改变可见性和焦点，不销毁四区 DOM，不触发保存或路由离开提醒。真正离页仍有 dirty 保护。
- 辅助面板：按钮标示展开状态；桌面和手机可关闭、按 Escape 关闭，关闭后焦点回到入口。阶段进度、日历、待验证行动保留原功能。

## 视觉规则草案

- 底色：冷雾灰绿 `#eef4f3`，低对比青蓝光斑，避免渐变主视觉抢夺书写。
- 主文本：深墨青 `#1b3133`；次级文本 `#52646a`；分隔线 `#c9d8d7`。
- 玻璃：只用于每日首屏和辅助面板，白色约 72% 不透明、轻模糊 12–18px、1px 明亮边缘和短阴影；不支持模糊时用接近不透明的表面。
- 书写面：`#fbfcfa` 近不透明，输入框与正文对比稳定。导航用低调实色/半透明，不叠多层玻璃。
- 主色继续来自现有六套主题或自定义颜色；聚焦环与按钮文字沿用现有对比计算。玻璃底层不得承载小号浅色文字。
- 字体：保留中文宋体作为复盘标题与正文的识别特征；操作、状态、导航用系统无衬线。日期使用大号、克制的数字排版作为唯一视觉记忆点。
- 节奏：桌面内容最大宽约 860px，表单行长舒适；内容组间 20–28px，面板内 24–32px。手机边距 16px，触控目标至少约 44px。
- 动效：只为抽屉、面板与选区切换提供短暂反馈；系统或用户减少动态效果时取消位移和渐变过渡。

## 设计自检

原版以三张深色统计卡、花体数字和四个大表单同时争夺注意力。新方向保留慎独的文气与日期感，但不用编号花体强化虚假的线性步骤。唯一较鲜明的元素是“今日日期”这一真实任务锚点，其余装饰退后。
